# DevSecOps learning

DevSecOps学習用の最小HTTPアプリです。Node.js標準モジュールのみを使い、外部依存はありません。

## 前提

- Node.js 24.x（npm同梱）
- 依存パッケージのインストールは不要です。
- `.nvmrc` に `24` を指定しています。`package.json` の `engines` は対応バージョンを示すもので、実行を強制的に制限するものではありません。

## 起動

```sh
npm start
```

ブラウザーで <http://127.0.0.1:3000> を開くと、`Hello DevSecOps` が表示されます。終了は `Ctrl+C` です。ポート3000が使用中の場合は起動に失敗します。

すべてのパスで同じ固定のプレーンテキストを返します。ルーティングやリクエスト本文の処理はありません。

## テスト

```sh
npm test
```

標準の `node:test` で実際のHTTPサーバーを空きポートに起動し、ステータス、ヘッダー、本文を検証します。テスト後にサーバーを終了します。

## ファイル構成

- `src/index.js`: HTTPアプリと起動処理
- `test/index.test.js`: HTTP応答のテスト
- `AGENTS.md`: 開発時の作業ルール

## セキュリティ

学習用に `127.0.0.1` のみで待ち受けます。入力を応答に埋め込まず、ファイルやコマンドとしても使用しません。今後、外部入力を使用する機能を追加するときは、型・長さ・許容値などを検証してください。

APIキー、パスワード、secretはコードやGitに保存しないでください。`.env` などはGit管理対象から除外していますが、`.gitignore` だけで秘密情報の混入を防げるわけではありません。`.env.example` を作る場合はダミー値のみを使用してください。

認証、TLS、レート制限は実装していません。外部公開する場合は公開範囲と必要な保護策を別途検討してください。
